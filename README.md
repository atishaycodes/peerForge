# PeerForge

PeerForge is a peer-to-peer mock interview platform where developers can practice interviews with each other, exchange roles, and improve their interview skills through feedback.

## Features

- Find and connect with interview partners.
- Conduct peer-to-peer mock interviews.
- Switch between interviewer and candidate roles.
- Exchange feedback after interviews.
- Track interview history and progress.

## Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **Real-time Communication:** Socket.IO, WebRTC
