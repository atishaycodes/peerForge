# Plan 03-01: Socket.IO Server Infrastructure & In-Memory Matchmaking Queue

## Objective
Install `socket.io`, attach Socket.IO to the Express HTTP server, implement cookie-based JWT socket authentication, build an in-memory matchmaking queue service with 45-second difficulty relaxation and 15-second mutual acceptance handshakes, and manage room provisioning.

<task id="03-01-02">
  <action>
    Create `server/services/matchmakingService.js` managing the matchmaking queue, pairing logic, and mutual acceptance handshakes.
    - Maintain in-memory `queue`: array of `{ socketId, userId, userDetails, track, difficulty, joinedAt }`.
    - Maintain in-memory `pendingMatches`: map of `matchId` -> `{ matchId, userA, userB, track, difficulty, acceptedUsers: Set, expiresAt, timer }`.
    - `addToQueue({ socketId, userId, userDetails, track, difficulty })`:
      - Remove any prior queue entries for this user/socket.
      - Add user with current `joinedAt` timestamp.
      - Attempt `findMatch()`.
    - `removeFromQueue(socketId)`:
      - Removes entry matching `socketId`.
    - `findMatch()`:
      - Iterates queued users; pairs two users if:
        1. Exact match: `userA.track === userB.track` AND `userA.difficulty === userB.difficulty`
        2. Relaxed match: either user has been in queue > 45 seconds AND `userA.track === userB.track`
      - When match found, removes both from queue and creates a pending match:
        - `matchId`: `match_${Date.now()}_${Math.random().toString(36).substring(2, 7)}`
        - 15-second expiration timer (`expiresAt = Date.now() + 15000`)
      - Returns match object or null.
    - `handleAccept({ matchId, userId })`:
      - Adds `userId` to `acceptedUsers`.
      - If both users accepted, generates `roomId: room_${matchId}` and resolves `{ confirmed: true, roomId, match }`.
    - `handleDecline({ matchId, userId })` or timeout:
      - Re-queues the other user at the front of the queue (`joinedAt: Date.now() - 40000` to preserve priority).
      - Drops declined user.
  </action>

<task id="03-01-03">
  <action>
    Create `server/socket/index.js` implementing socket authentication middleware and event dispatchers.
    - Socket authentication middleware:
      - Parses cookie string from `socket.handshake.headers.cookie` using `cookie-parser` or simple regex.
      - Extracts `auth_token` and verifies using `jwt.verify(token, process.env.JWT_SECRET)`.
      - If token is missing or invalid, rejects connection with `Authentication error`.
      - Attaches decoded user info (`socket.user = decoded`) to socket.
    - Connection handler:
      - Listen to `queue:join` (`{ track, difficulty }`) -> calls `matchmakingService.addToQueue(...)`. If match created, emits `match:found` to both user sockets.
      - Listen to `queue:leave` -> calls `matchmakingService.removeFromQueue(socket.id)`.
      - Listen to `match:accept` (`{ matchId }`) -> calls `matchmakingService.handleAccept`. If both accept, emits `match:confirmed` with `{ roomId, track, difficulty }` to both sockets.
      - Listen to `match:decline` (`{ matchId }`) -> calls `matchmakingService.handleDecline`. Emits `match:cancelled` to both sockets and re-queues accepted peer.
      - Listen to `invite:create` (`{ track, difficulty }`) -> creates unique room code and returns `{ inviteCode, roomId }`.
      - Listen to `disconnect` -> calls `matchmakingService.removeFromQueue(socket.id)` and cleans up pending matches.
  </action>
