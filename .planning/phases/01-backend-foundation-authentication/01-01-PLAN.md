# Plan 01-01: Server Scaffolding & MongoDB User Schema

## Objective
Establish the foundational Express.js server, configure MongoDB database connectivity via Mongoose, define the unified User schema with secure bcrypt password hashing and an embedded profile subdocument, and setup the root concurrent development workflow.

---

## Tasks

<task id="01-01-01">
  <action>
    Install Express backend dependencies and devDependencies, then update the root package.json scripts to support running frontend and backend concurrently.
    Dependencies to install: `express`, `mongoose`, `jsonwebtoken`, `bcryptjs`, `cookie-parser`, `cors`, `dotenv`.
    DevDependencies to install: `nodemon`, `concurrently`.
    Update package.json "scripts":
      - `"dev": "concurrently \"vite\" \"nodemon server/server.js\""`
      - `"server": "nodemon server/server.js"`
      - `"client": "vite"`
  </action>
  <read_first>
    package.json
  </read_first>
  <acceptance_criteria>
    - package.json contains "express", "mongoose", "jsonwebtoken", "bcryptjs", "cookie-parser", "cors", and "dotenv" in dependencies
    - package.json contains "nodemon" and "concurrently" in devDependencies
    - package.json "scripts" contains `"dev": "concurrently \"vite\" \"nodemon server/server.js\""`
  </acceptance_criteria>
  <verify>
    node -e "const pkg = JSON.parse(require('fs').readFileSync('package.json', 'utf8')); const reqs = ['express', 'mongoose', 'jsonwebtoken', 'bcryptjs', 'cookie-parser', 'cors', 'dotenv']; const missing = reqs.filter(r => !pkg.dependencies[r]); if (missing.length) throw new Error('Missing dependencies: ' + missing.join(', '));"
  </verify>
</task>

    - `.env` created with default development values if it does not already exist.
    - `server/config/db.js` exports an async function `connectDB` that connects to Mongoose using `process.env.MONGODB_URI`, logs connection success host, and handles connection errors gracefully.
  </action>

<task id="01-01-03">
  <action>
    Create `server/models/User.js` with a unified Mongoose schema per Decision D-06.
    Schema requirements:
    - `name`: String, required, trim
    - `email`: String, required, unique, lowercase, trim
    - `passwordHash`: String, required
    - `profile`: embedded subdocument with:
        - `bio`: String, default: ""
        - `targetRoles`: [String], default: []
        - `skills`: [String], default: []
        - `timeZone`: String, default: "UTC"
    - timestamps: `{ createdAt: true, updatedAt: true }`
    - Pre-save hook or helper method for password hashing using `bcryptjs` with 10 salt rounds.
    - Instance method `comparePassword(candidatePassword)` returning a Promise<boolean>.
    - Instance method or `toJSON` transform to strip `passwordHash` when converting to JSON.
  </action>
  <read_first>
    .planning/phases/01-backend-foundation-authentication/01-CONTEXT.md
  </read_first>
  <acceptance_criteria>
    - File `server/models/User.js` exists and exports Mongoose model `User`
    - Schema includes `name`, `email`, `passwordHash`, and embedded `profile`
    - `User.prototype.comparePassword` is defined
  </acceptance_criteria>
  <verify>
    node -e "import('./server/models/User.js').then(m => { const User = m.default || m.User; if (!User || !User.schema) throw new Error('User model not exported properly'); const paths = Object.keys(User.schema.paths); if (!paths.includes('email') || !paths.includes('passwordHash') || !paths.includes('name')) throw new Error('User schema missing required fields'); console.log('User model verified'); });"
  </verify>
</task>
