# Plan 01-03: Frontend Integration, State Management & Protected Routing

## Objective
Configure the Vite development proxy for seamless backend API integration, create an `AuthContext` for global authentication state management, connect the existing `LoginForm.jsx` to live API endpoints, implement protected routing with `react-router-dom`, and build a clean Dashboard page with session details and logout capabilities.

---

## Tasks

<task id="01-03-01">
  <action>
    Install `react-router-dom` and configure the Vite development server proxy to forward `/api` requests to the Express backend.
    - Run `npm install react-router-dom`.
    - Update `vite.config.js` to include `server.proxy`:
      ```javascript
      server: {
        proxy: {
          '/api': {
            target: 'http://localhost:5000',
            changeOrigin: true,
            secure: false,
          },
        },
      },
      ```
  </action>
  <read_first>
    vite.config.js
    package.json
  </read_first>
  <acceptance_criteria>
    - `package.json` contains `react-router-dom` in dependencies
    - `vite.config.js` contains `server.proxy` forwarding `/api` to `http://localhost:5000`
  </acceptance_criteria>
  <verify>

<task id="01-03-02">
  <action>
    Create `src/context/AuthContext.jsx` with an `AuthProvider` and custom hook `useAuth()`.
    - Maintain state: `user` (default: null), `loading` (default: true), `error` (default: null).
    - On component mount, trigger `checkAuth()` by calling `fetch('/api/auth/me', { credentials: 'include' })`. If 200, set `user` with response data; else set `user` to null. Set `loading` to false.
    - Implement `login({ email, password })`:
      - POST to `/api/auth/login` with `{ email, password }` and `credentials: 'include'`.
      - If successful, set `user` to `res.user`, clear `error`, return `{ success: true }`.
      - If error, set `error` and return `{ success: false, error: err.message }`.
    - Implement `register({ name, email, password })`:
      - POST to `/api/auth/register` with `{ name, email, password }` and `credentials: 'include'`.
      - If successful, set `user` to `res.user`, clear `error`, return `{ success: true }`.
      - If error, set `error` and return `{ success: false, error: err.message }`.
    - Implement `logout()`:
      - POST to `/api/auth/logout` with `credentials: 'include'`.
      - Clear `user` to null, clear `error`.
  </action>
  <read_first>
    .planning/phases/01-backend-foundation-authentication/01-CONTEXT.md
  </read_first>
  <acceptance_criteria>
    - `src/context/AuthContext.jsx` exists and exports `AuthProvider` and `useAuth`
    - `AuthContext` provides `user`, `loading`, `login`, `register`, `logout`
    - All fetch requests include `credentials: 'include'`
  </acceptance_criteria>
  <verify>
    node -e "const fs = require('fs'); const content = fs.readFileSync('src/context/AuthContext.jsx', 'utf8'); if (!content.includes('useAuth') || !content.includes('AuthProvider') || !content.includes('credentials')) throw new Error('AuthContext invalid'); console.log('AuthContext verified');"
  </verify>
</task>
