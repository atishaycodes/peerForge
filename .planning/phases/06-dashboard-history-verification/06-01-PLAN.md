# Plan 06-01: Session History & Analytics Backend REST Endpoints

## Objective
Implement backend API routes and controllers to query past interview sessions, aggregate competency analytics ratings, and retrieve upcoming scheduled interview slots for the authenticated developer.

---

## Tasks

<task id="06-01-01">
  <action>
    Create `server/controllers/sessionController.js` implementing:
    1. `getSessionHistory(req, res)`:
       - Find `Session` documents where `participants.user` contains `req.user._id`.
       - Populate participant users (`name`, `email`, `profile.avatarUrl`, `profile.skills`, `profile.targetRoles`).
       - For each session, find associated `Feedback` documents:
         - Find feedback received by `req.user._id` (`candidate: req.user._id`) and feedback given by `req.user._id` (`reviewer: req.user._id`).
         - If feedback `isRevealed === true`, attach the received scores, strengths, improvements, and privateNotes to the session record.
         - If `isRevealed === false`, attach `{ isRevealed: false }` to protect symmetric blind reveal.
       - Sort by `createdAt: -1` (newest first).
       - Return `{ success: true, count, sessions }`.
    2. `getUserAnalytics(req, res)`:
       - Find all revealed `Feedback` documents where `candidate: req.user._id` and `isRevealed: true`.
       - Calculate total completed sessions count.
       - Compute average ratings for:
         - `codeCorrectness`
         - `problemSolving`
         - `communication`
         - `architecture`
         - `overallComposite` (average across all 4 competencies)
       - If zero feedback exists, return zeros/empty state with `totalSessions: 0`.
       - Return `{ success: true, analytics: { totalSessions, overallAverage, competencies: { codeCorrectness, problemSolving, communication, architecture } } }`.
    3. `getUpcomingSessions(req, res)`:
       - Find `Session` documents where `participants.user` contains `req.user._id` AND `status === 'active'` (or upcoming scheduled time > now).
       - Populate peer participant details.
       - Return `{ success: true, upcoming: sessions }`.
  </action>
  <read_first>

    .planning/phases/06-dashboard-history-verification/06-CONTEXT.md
  </read_first>
  <acceptance_criteria>

</task>
