# Plan 04-02: WebRTC Audio/Video Hook, Media Controls & Quiet Video Tiles

## Objective
Implement client-side WebRTC peer connection management via a custom `useWebRTC` hook configured with Google STUN servers and graceful fallback, alongside quiet graphite video tiles displaying local and remote video streams, audio wave/mute indicators, participant role badges, and AV control toggles.

---

## Tasks

<task id="04-02-01">
  <action>
    Create `src/hooks/useWebRTC.js` managing peer-to-peer audio/video streaming via WebRTC.
    - Configuration: STUN servers (`stun:stun.l.google.com:19302`, `stun:stun1.l.google.com:19302`).
    - State:
      - `localStream`: User's camera & microphone `MediaStream`.
      - `remoteStream`: Remote peer's incoming `MediaStream`.
      - `isMuted`: Boolean microphone state (default: false or true if permission denied).
      - `isVideoOff`: Boolean camera state (default: false or true if permission denied).
      - `isScreenSharing`: Boolean screen share state.
      - `connectionStatus`: `'disconnected' | 'connecting' | 'connected' | 'failed'`.
      - `permissionError`: Error message if camera/microphone access is denied or unavailable.
    - Functionality:
      - `startLocalStream()`: Requests `navigator.mediaDevices.getUserMedia({ video: true, audio: true })`. Gracefully handles `NotAllowedError` or `NotFoundError` without throwing; sets `permissionError` and allows avatar monogram fallback.
      - `initiateCall(targetSocketId)`: Caller creates `RTCPeerConnection`, adds local tracks, creates SDP offer (`createOffer()`), sets local description, and emits `webrtc:offer` over socket.
      - Handle incoming `webrtc:offer`: Callee creates `RTCPeerConnection`, sets remote description, adds local tracks, creates SDP answer (`createAnswer()`), sets local description, and emits `webrtc:answer` over socket.
      - Handle incoming `webrtc:answer`: Caller sets remote description.
      - Handle incoming `webrtc:ice-candidate`: Adds candidate via `peerConnection.addIceCandidate()`.
      - `toggleAudio()`: Enables/disables local audio tracks and emits `room:media-status` to partner.
      - `toggleVideo()`: Enables/disables local video tracks and emits `room:media-status` to partner.
      - `toggleScreenShare()`: Toggles screen sharing via `navigator.mediaDevices.getDisplayMedia`.
      - `cleanup()`: Stops all tracks and closes peer connection cleanly upon unmount or leave.
  </action>
