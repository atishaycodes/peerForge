# Plan 04-01: WebRTC Signaling Gateway, Room Session State & Editor Dependencies

## Objective
Install `@monaco-editor/react` for the collaborative code editor and build the backend Socket.IO signaling gateway with room session state management (peer connection signaling, code synchronization relays, cursor broadcasts, role swapping, problem selection, and room lifecycle cleanup).

<task id="04-01-02">
  <action>
    Create `server/socket/roomSignaling.js` to manage room state and peer signaling.
    - Maintain in-memory `activeRooms` Map:
      `roomId` -> `{ roomId, participants: Map(socketId -> { userId, userDetails, role, hasMedia: { audio: false, video: false } }), code: string, language: string, activeProblemId: string, timer: { startedAt, durationSeconds: 3600, isRunning: true, phase: 1 }, lastActivity: number }`
    - Export functions:
      1. `joinRoom(io, socket, { roomId, track, difficulty })`:
         - Enforce room capacity: maximum 2 active participants per room (rejects third party if room is full for SEC-02).
         - Assign initial role: first participant becomes `"candidate"` (or interviewer), second becomes `"interviewer"`.
         - Add socket to Socket.IO room channel `socket.join(roomId)`.
         - Store participant details in `activeRooms`.
         - Emit `room:state` to the joining socket with current code, language, problemId, timer, roles, and other participants.
         - Broadcast `room:peer-joined` to the other peer in the room.
      2. `handleSignaling(io, socket, { roomId, type, payload, targetSocketId })`:
         - Relay WebRTC signaling payloads (`webrtc:offer`, `webrtc:answer`, `webrtc:ice-candidate`) to the other peer in the room.
         - Attach sender info (`senderSocketId: socket.id`, `senderUserId: socket.user._id`).
      3. `handleCodeSync(io, socket, { roomId, code, version, cursor })`:
         - Update cached `room.code` and `room.lastActivity`.
         - Broadcast `room:code-update` and `room:cursor-update` to `socket.to(roomId)` with latency < 150ms.
      4. `handleLanguageChange(io, socket, { roomId, language })`:
         - Update cached `room.language`.
         - Broadcast `room:language-updated` to `socket.to(roomId)`.
      5. `handleProblemChange(io, socket, { roomId, problemId })`:
         - Update cached `room.activeProblemId`.
         - Broadcast `room:problem-updated` to `socket.to(roomId)`.
      6. `handleRoleSwap(io, socket, { roomId })`:
         - Invert participant roles in `activeRooms`.
         - Broadcast `room:role-swapped` to all sockets in `roomId` with new role map.
      7. `leaveRoom(io, socket, roomId)`:
         - Remove participant from `activeRooms`.
         - Notify remaining peer via `room:peer-left`.
         - If room is empty, clean up memory entry after a short grace period.
  </action>
