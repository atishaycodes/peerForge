## Objective
Build the curated interview problem bank, sandboxed in-browser code execution utility, collapsible problem drawer, synchronized Monaco code editor, test cases & console drawer, 60-minute interview timer with dual 30m role swapping, and assemble the full 3-column Interview Room UI (`/room/:roomId`).

<task id="04-03-02">
  <action>
    Create `src/utils/codeExecutor.js` for safe in-browser JavaScript execution and test evaluation.
    - Features:
      - Intercepts and captures `console.log`, `console.info`, `console.warn`, `console.error` messages into an output log buffer.
      - Executes code in a sandboxed context or Web Worker with a 2000ms timeout guard to prevent infinite loops.
      - Runs user-defined function against the problem's `testCases`.
      - Returns:
        - `success`: boolean
        - `testResults`: array of `{ index, input, expected, actual, passed, error }`
        - `consoleLogs`: array of `{ type, message, timestamp }`
        - `executionTimeMs`: number
        - `error`: error message string if syntax or runtime crash occurred
    - If non-JS language is chosen (Python, C++, Java), provides simulated evaluation with clear notice.
  </action>
