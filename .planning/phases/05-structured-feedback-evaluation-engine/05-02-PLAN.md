# Plan 05-02: Interactive Rubric Form, Live Blind Waiting Room & Unlocked Scorecard UI

## Objective
Build the post-session peer evaluation UI: interactive 4-dimension rubric scoring, structured qualitative input with character counters, real-time blind waiting room over Socket.IO, and immediate unlocked scorecard display with dimension breakdown bars and private candidate notes.
