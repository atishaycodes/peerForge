# Plan 02-02: Profile Screen, Tag Input & Dashboard Onboarding Banner

## Objective
Deliver a responsive `/profile` page with interactive skill tag selection, target roles, browser timezone detection, and availability toggles, integrated with `AuthContext` and a non-blocking onboarding progress banner on the Dashboard.

---

## Tasks

<task id="02-02-01">
  <action>
    Update `src/context/AuthContext.jsx` to add `updateProfile(profileData)` method.
    - Sends `PUT /api/profile` with `headers: { "Content-Type": "application/json" }`, `credentials: "include"`, and serialized `profileData`.
    - On success (200), updates `user` state with the returned updated user object and returns `{ success: true, user: res.user }`.
    - On error, catches and returns `{ success: false, error: err.message }`.
    - Exposes `updateProfile` in the context value object.
  </action>
